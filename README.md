# PulseZones — один сайт, несколько языков

Готовы все десять языков: русский (`ru/`), английский (`en/`), испанский (`es/`), португальский Бразилии (`pt-br/`), немецкий (`de/`), французский (`fr/`), итальянский (`it/`), польский (`pl/`), турецкий (`tr/`) и грузинский (`ka/`). Один шаблон, общие стили, скрипт и оптимизированные изображения.

## Посмотреть локально

Откройте `dist/index.html` двойным щелчком и выберите язык. Прямые страницы находятся в папках соответствующих языков. Переключатель сохраняет текущий раздел. Текст уже находится в HTML: для чтения и перехода между языками JavaScript не нужен.

## Разместить на GitHub Pages

1. Создайте репозиторий и загрузите **содержимое этой папки в корень репозитория**, включая `.github/workflows/pages.yml`.
2. В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Если основная ветка называется не `main`, измените её имя в `.github/workflows/pages.yml`.
4. Выполните push в `main` либо запустите **Actions → Publish PulseZones to GitHub Pages → Run workflow**.
5. Сборка автоматически получит настоящий адрес Pages, создаст canonical, взаимные hreflang, x-default, sitemap.xml и опубликует папку `dist`.

Настройки адресов рассчитаны и на `username.github.io/repository/`, и на корневой сайт, и на собственный домен, настроенный через GitHub Pages. Укажите собственный домен в Pages до следующей сборки, чтобы метаданные использовали его.

Запускать платные сервисы и устанавливать библиотеки не нужно. Используется Node.js 22 и стандартные модули.

## Локальная сборка

```powershell
node build.mjs
node check.mjs
```

Без SITE_URL создаётся локальный предпросмотр без выдуманного публичного адреса. Для самостоятельной публикации готовых файлов задайте реальный адрес:

```powershell
$env:SITE_URL = 'https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/'
node build.mjs
node check.mjs
```

`sitemap.xml` формируется при сборке с публичным адресом. На проектном сайте `/repository/robots.txt` не заменяет `/robots.txt` домена, поэтому после публикации отправьте полный адрес карты сайта через Search Console. Доступность страниц и метаданные не гарантируют индексацию: её проверяют после публикации.

## Редактировать сайт

- `source/template.html` — общая разметка; `{{t001}}` и другие метки подставляются при сборке.
- `locales/*.json` — переводы, включая SEO-описания, подписи для доступности и название меню языка.
- `public/` — файлы, которые копируются без изменений в корень сайта, включая подтверждение Google Search Console.
- `assets/styles.css` — общее оформление.
- `assets/script.js` — калькулятор и сохранение раздела при смене языка.
- `assets/phone-*.webp` — общие изображения для обеих версий; картинки нижних блоков загружаются при прокрутке.

Не редактируйте собранный `dist` вручную: новая сборка заменяет файлы.

## Добавить следующий язык

Скопируйте `locales/en.json` в файл с кодом следующего языка, переведите все значения и включите соответствующий язык (`enabled: true`) в `languages.json`. Сборка автоматически добавит его в меню, карту сайта и hreflang. Для португальского код файла — `pt-br`, атрибут hreflang — `pt-BR`. Сборка завершится ошибкой, если перевод неполный.

Подписи зон в калькуляторе также берутся из перевода. Изображения интерфейса общие и сейчас на английском; статьи, меню и подписи переведены полностью.
